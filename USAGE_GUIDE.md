# 📖 Financial RAG Agent - Usage Guide

## 🎯 What This App Does

This is a **complete RAG (Retrieval Augmented Generation) + Agentic AI system** for financial analysis. It demonstrates:

1. **Autonomous Planning**: The agent analyzes your question and decides which tools to use
2. **Real Data Processing**: Computes financial ratios from actual quarterly data
3. **Information Retrieval**: Searches through 21 news items to find relevant context
4. **LLM Integration**: Synthesizes everything into a comprehensive answer

---

### **Step 1: Choose Mode**

#### **Mock Mode (No API Key)**

## 💡 Tips for Best Results

### ✅ **Good Questions:**
- Specific about companies: "What is Apple's ROE?"
- Clear comparison: "Compare AAPL and MSFT margins"
- Focused metrics: "Show me NVIDIA's profitability metrics"
- Risk-oriented: "What risks face Tesla?"

### ⚠️ **Questions That Won't Work Well:**
- Companies not in dataset: "Analyze Netflix" ❌ (not in our data)
- Real-time data: "What's Apple's stock price today?" ❌ (we have quarterly data)
- Non-financial: "Who is Apple's CEO?" ❌ (focus on financial metrics)
- Future predictions: "Will NVDA stock go up?" ❌ (we analyze historical data)

## 🔍 Understanding the Workflow

### **What Happens Behind the Scenes:**

```
Your Question
    ↓
📋 AGENT PLANNER
    ├─ Detects question type
    ├─ Extracts company tickers (AAPL, MSFT, etc.)
    ├─ Selects appropriate tools
    └─ Creates execution plan
    ↓
🔧 TOOL EXECUTOR
    ├─ fetch_financials() → Gets raw data
    ├─ compute_ratios() → Calculates metrics
    ├─ retrieve_context() → Searches news
    └─ compare_two_tickers() → Side-by-side comparison
    ↓
🧠 LLM SYNTHESIZER
    ├─ Takes all tool results
    ├─ Combines financial data + news context
    └─ Generates comprehensive answer
    ↓
📊 Your Answer + Metrics
```

## 📈 Financial Metrics Explained

When you see metrics in the output, here's what they mean:

| Metric | Description | Good Value |
|--------|-------------|------------|
| **Revenue** | Total sales in millions | Higher is better |
| **Net Margin** | Profit % after all expenses | >15% is strong |
| **ROE** | Return on Equity | >15% is good |
| **ROA** | Return on Assets | >5% is solid |
| **Debt/Equity** | Financial leverage | <1.0 is conservative |
| **Operating Margin** | Operating profit % | >10% is healthy |

## 🐛 Troubleshooting

### **"Nothing happens when I click ANALYZE"**

**Check:**
1. Did you enter a question in the text box?
2. Try clicking one of the example buttons first
3. Check browser console for JavaScript errors
4. Try refreshing the page

### **"No documents found"**

**Possible causes:**
- Question doesn't mention any company name or ticker
- Try being more specific: "Apple's metrics" instead of "tech metrics"
- Fallback keyword search may not match – try different wording

### **"Tool execution failed"**

**Possible causes:**
- Ticker not in dataset (only AAPL, MSFT, NVDA, GOOGL, AMZN, META, TSLA)
- Data loading issue – refresh the page
- Check the error details in the expander

### **"API key not working"**

**Steps:**
1. Make sure you clicked "💾 Save Config" after entering key
2. Check if you selected the right provider (OpenAI vs Anthropic)
3. Verify API key is valid and has credits
4. Look for error details in expanders
