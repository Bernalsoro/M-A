═══════════════════════════════════════════════════════════════════════════
   ¿POR QUÉ FALLA EL IMPORT?
═══════════════════════════════════════════════════════════════════════════

El código hace esto:

    import sys
    from pathlib import Path
    sys.path.append(str(Path(__file__).parent.parent))

    from models.dcf import DCFModel  ← Busca en M-A/models/

Esto significa:
• __file__ = examples/nvidia_case_study.py
• __file__.parent = examples/
• __file__.parent.parent = M-A/   ← Añade esto al path

Entonces Python busca:
• M-A/models/dcf.py  ✅
• M-A/analysis/financial_ratios.py  ✅

PERO si ejecutas desde otro directorio, Python NO encuentra las carpetas.
