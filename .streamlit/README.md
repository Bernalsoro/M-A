# Streamlit Configuration

This directory contains configuration files for the Streamlit application.

## Files

- `config.toml`: Main configuration file for Streamlit app
  - Theme colors and styling
  - Server settings for deployment

## Customization

You can modify `config.toml` to change:
- **Primary color**: Brand color for interactive elements
- **Background colors**: Main and secondary backgrounds
- **Text color**: Default text color
- **Font**: Choose from "sans serif", "serif", or "monospace"

For more configuration options, see:
https://docs.streamlit.io/library/advanced-features/configuration
